# 🛒 Retail AI Platform

A full-stack data analytics dashboard built with Streamlit.

## 🚀 Features
- 🔐 Authentication system (Login/Register/Forgot Password)
- 📊 Interactive dashboard
- 📈 Sales forecasting (Prophet & ML)
- 🤖 AI-powered assistant
- 📌 Business insights
- 👤 Profile management

## 🛠 Tech Stack
- Python
- Streamlit
- SQLite
- Pandas, Scikit-learn
- OpenAI API

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
